# Rally One — 3D Tennis

ブラウザで動く3Dテニス。ビルド不要、サーバー不要、ネット接続も不要。

**▶ 遊ぶ: https://atsushi-green.github.io/3D-tennis/**
（ラリー中はキーボードが必要なので **PC 推奨**。スマホではスタート画面までしか操作できません）

## 動かす

**`index.html` をダブルクリックするだけ。** ブラウザが開いたら、スタート画面で設定して「試合開始」を押す（キーボードなら Space）。

（three.js は `vendor/three.min.js` に同梱してあるので、オフラインでも動きます）

## 操作

| キー | 動作 |
| --- | --- |
| ←→ | 左右移動 ／ 打つ方向の指定 ／ サーブのコース（T・ボディ・ワイド。ワイド方向へ Shift を押しながら離すと**角度をつけたサービス**＝ワイドより外へ切れるが、その分フォールトもしやすい） |
| ↑↓ | 前後移動 ／ サーブのトス中は着地の深さ（↑＝深く／↓＝浅く） |
| B / V / C | 押しっぱなしでテイクバックを溜め、離すと打つ（B＝フラット／V＝トップスピン／C＝スライス。**Cをほとんど溜めずに離すとドロップショット**＝ネット際に落ちて弾まない短い球になる。押したキーがそのまま結果になり、当たるまで押し続ける必要はない。クリック/タップでも可＝フラット）。**相手のサーブを待っている間も押しっぱなしにして構えていられる**（＝ラケットを引いて待つ。サーブが来たら離すだけでレシーブできる。下記参照）。サーブは1回目が即トス、トス中の2回目から溜められる。溜め具合は画面下のバーに表示（サーブ中はバーに**線**が出る。下記参照）。グラウンドストローク・サーブ以外（スマッシュ・ボレー・CPU/AIの打球）はどのキーでもフラット固定 |
| Shift | ロブ（サーブのトス中はコース選択に使う。上記参照） |
| K | **キックサーブ**（必殺技で選んであるとき）。自分のサーブで B/V/C の代わりに押してトスを上げ、溜めて離す操作は同じ。B/V/C で上げたトスは普通のサーブになる。サーブ以外では何もしない |
| Q / E | （ダブルス）AIパートナーに前へ詰める／ベースラインまで下がるを指示（下がれと言った間は、ロブを叩きにネット際まで出ていきません）。サーブ前に押すと、パートナーがその場で前（ネット際）／後ろ（ベースライン付近）に立ち直す。ただしパートナーがサーブ・レシーブ担当の番は動かず、指示は打った後のラリーにだけ効く |
| R / F | （ダブルス・サーブ前）自分が前（ネット際）／後ろ（ベースライン付近）に立ち直す。選んだ位置は次の番にも引き継がれる。自分がサーブ・レシーブ担当の番は動かせない |
| Space | ポイント間のリプレイをスキップ（試合中はこの用途のみ。他のキーではスキップされない）／チェンジエンズの休憩を切り上げる／試合後のスタッツ画面を閉じて次の試合へ（Enter でも可。他のキーでは閉じない） |
| 任意のキー（開始前） | 選んである形式で開始（Space など。形式を指定する S・D、設定用の 1〜0・G・Z・X、練習モードの P と Esc は除く）。なお「画面のどこでもクリックで開始」はボタン・つまみバーの操作と衝突するため廃止した |
| S / D（開始前） | S＝シングルス、D＝ダブルス（あなた＋AIパートナー vs CPU2人）を選んでそのまま開始。Space などの「開始」キーは**いま選ばれている形式**で始めるので、形式まで指定したいときはこの2つを使う |
| P（開始前） | 練習モード（チュートリアル）のレッスン一覧を開く。一覧の中は矢印キーで選び Space・Enter で始める（クリックでも可）、Esc で設定画面へ戻る。下記「練習モード」参照 |
| N / Esc（練習モード中） | N＝次のレッスンへ（最後のレッスンの次は一覧へ）、Esc＝レッスン一覧へ戻る。試合中はどちらも何もしない |
| 1 / 2（コイントスに勝ったときだけ） | サーブ／レシーブを選ぶ。Space・Dの直後、コイントスに人間が勝ったときだけこの選択画面になる（CPUが勝った場合は自動で選ぶ） |
| 1 / 2 / 3 / X（開始前） | CPU/AIの強さを Easy / Normal / Hard / **Extreme** から選ぶ（既定は Normal）。Extreme だけ数字ではなく X なのは 1〜0 が他の設定で埋まっているため |
| 4 / 5 / 6（開始前） | コートサーフェスを ハード / クレー / 芝 から選ぶ（既定はハード。選ぶと背後のコートの色もすぐ変わる） |
| 7 / 8 / 9 / 0（開始前） | CPU/AIのプレースタイルを なし / サーブ&ボレー / リトリーバー / ベースライナー から選ぶ（既定はなし。強さとは別軸） |
| G（開始前） | **ガイド付きモード**の入/切（既定は なし）。溜めている間ずっと「いまキーを離したらどこへ飛ぶか」を、コート上の輪＋線と画面下のタイミング目盛り（引っ張り／素直／流し）で見せる。ライン際を狙っているときは輪が「散る幅」まで大きくなり、警告色になる。打球そのものは変わらない練習用の表示 |
| Z（開始前） | **必殺技**のプリセットを切り替える（なし → おすすめ4種 → すべて → なし）。1つずつの入/切はマウスで行う |
| マウス（開始前） | **スタート画面はすべてマウスで設定できる。** 試合形式・CPUの強さ・サーフェス・ガイド・プレースタイル・必殺技はボタンで選び、能力値はつまみバーをドラッグ（またはバーの上をクリック）で決める。「試合開始」ボタンで開始。どのボタンにも対応するキーが添えてあり、キーボードでも同じ操作ができる |

**打つ方向は「←→ でどちら側か」＋「離すタイミングで角度」**で決まる。ボールが手の届く
ところへ来るより早く振り出すほど引っ張り、引きつけて離すほど流し（フォアとバックでは
体を横切る向きが逆なので、ずれる向きも逆）。目一杯ずらすとサイドライン際まで角度が
つく代わりに狙いが荒れ、15%ほどはサイドアウトする（←→ の狙いだけで打つぶんには
外れない）。感覚がつかめないうちは、スタート画面の**ガイド**（G）を入れると、
溜めている間ずっと予想着地点・今のタイミング・ライン際の警告が表示される。

1セットマッチ（6ゲーム先取、2ゲーム差）。

**スタート画面の「必殺技」で、使う技を複数選べます**（既定は なし）。詳しくは
[必殺技](#必殺技)を参照。

**スタート画面の「選手設定」で、4人（YOU／パートナー／CPU／CPU2）の能力値を1〜5で
決められます。** 項目はフォアハンド・バックハンド・ボレー・スマッシュ・サーブ・体力・
移動速度・リーチ&読み・安定感・ネット志向の10種類。タブで誰の設定かを切り替え、各行の
つまみバーをドラッグ（またはバーの上をクリック）すると値が決まります（「既定に戻す」
「ランダム」も同じパネルの右上）。

- **すべて3が既定で、そのときは倍率がちょうど1.0＝これまでと同じ強さ**です。難易度
  （Easy/Normal/Hard/Extreme）やプレースタイルとは別の層で、掛け算として効きます（例：「Hard の
  CPU の、さらにサーブだけ弱い相手」も作れる）。
- フォア／バック／ボレー／スマッシュ／サーブは**打球の速さ**（同じ狙いへより短い時間で
  届く＝速く鋭い球）に効きます。ボレーは加えて「角度をつけて決めにいける度合い」、
  サーブは「ゲージの線を超えてもフォールトしない余裕」（人間のみ）も広がります。
- 体力はバテにくさと回復量、移動速度は走る速さ、リーチ&読みは手の届く範囲とAIの反応の
  速さに効きます。
- 安定感は、AIなら「わざとラインを割る確率の低さ」、人間なら「打点がずれてもコースが
  曲がりにくい」に効きます。ネット志向はシングルスでAIが前に出る頻度（人間は自分で
  動くので効きません。パネル上でも薄く表示されます）。

**スマッシュのチャンスには、先回りすべき地点がコートに出ます。** 高い球（ロブなど）が
来て、それを**ノーバウンドで**打てる高さ（1.8〜2.5m）で捉えられる場所があるとき、そこに
輪のマーカーが出ます（バウンドさせてから打てる球は、立つ位置がベースラインのはるか後ろに
なって決め球にならないので案内しません）。**ベースライン付近（1m以内）に立っている間は出ません** —
そこから打点まで走ると走るだけで滞空時間を使い切ってしまい、どのみち溜めが間に合わないためです。
前に詰めた瞬間から出ます。
輪の中に立って足を止め、溜めてから離せばスマッシュになります。外側の輪は打点までの残り時間で、
内側の輪に重なった瞬間が打つタイミング。色は 水色＝走れば間に合う／黄色＝もう届く位置にいる／
赤＝全力で走っても溜めが間に合わない（スマッシュは諦めて普通に返すほうが安全）。
スマッシュには「高い打点」だけでなく「溜め」も要り、走っている間は溜められないので、
**打点の手前で止まっておく**のがコツです。輪の中で溜めている間はラケットを頭の後ろに担いだ
**振りかぶり**の構えになり、離すと**ジャンプして上から振り下ろす**（着地までがワンモーション）。

**打点のタイミングでもコースが変わります。** ボールを前（遠く）で捉えるほど「引っ張り」、
引きつけて近くで打つほど「流れ」ます。フォアハンドとバックハンドでは体を横切る向きが
逆なので、引っ張る/流れる方向も逆になります。←→ の方向指定と組み合わせて使えます。

**選手は全員右利きです。** 自分から見て右側（画面の右）に来た球がフォアハンド、左側が
バックハンドになります（相手は手前を向いているので、画面では左右が逆に見えます）。

**レシーブは、サーブが来る前からラケットを引いて待てます。** 相手のサーブを待っている
間に B/V/C を押しておくと、その場でテイクバックを引いたまま溜め続けられます（構えも
画面に出ます）。サーブが飛んできたら**離すだけ**なので、「反応する → 走る → 押す →
離す」を 0.6 秒の中で全部やる必要がなくなります。足を止めて待てていればそのぶん溜まって
いるので、**深く強いリターン**が返せます（走らされた球は溜めが抜けるので、つなぎの球に
なります）。1本目がフォールトしても、押したままなら握り直さずにそのまま2本目を待てます。

**レシーブの1打だけ、振り出しの猶予と手の届く範囲が広くしてあります。** サーブの球速・
コース・深さはそのまま（＝体感の速さは変わりません）で、「早く振り出してもラケットが
ボールを待つ」時間だけ 0.26 秒 → 0.42 秒に広げ、リーチも 1.15 倍にしてあります。
サーブが打たれてから打点までは約 0.6 秒しかなく、その中で走って振るのは元々ほぼ
不可能（実測でレシーブ失敗のほとんどは「届かなかった」ではなく「空振り」でした）。
早めに振ったぶんは引っ張り、引きつけたぶんは流しになる関係はそのままです。

**サーブは「溜めゲージの線」で離すのが最強です。** サーブの溜め中だけ、ゲージの9割の
位置に白い線が出ます。線に届いたところが最大威力（ゲージも白く光る）で、そこから先は
**溜めても威力は増えず、超えた度合いに応じてフォールトする確率だけが上がります**
（超えている間はゲージが赤くなります）。線をわずかに超えた程度なら見逃されますが、
満タンまで溜めると3割前後、それ以上ならほぼ確実にロングかサイドアウトになります。
**満タンの後も押し続けると溜めが抜けていきます**（ゲージが減っていき、トスが手元に落ちて
くる頃に空になる）。ゲージが線より下へ戻ると威力も落ちますが、赤いまま＝押しすぎて
外れやすいのは変わりません。
線ちょうどで離せたときの球は、以前の最大威力より一段速い（フラットで 205km/h 前後まで出る）。

**線ちょうどの全力サーブなら、Hard 以上の相手からもエースが取れます。** CPU はサーブを見てから
動くのではなく打たれる前の読みで出足が決まり、読めたときは速く、外れたときは遅れます
（強い相手ほど読みが当たれば速い代わりに、外れたときの遅れも大きい）。遅れが大きいほど
走らないと届かないコースが抜けるので、エースになりやすいのは**角度 ＞ センター ＞ ワイド**、
レシーバーめがけて飛ぶボディはまずエースになりません。実測（線ちょうどのフラット、入った
サーブのうちエースの割合）：Normal センター約30%・角度約80% ／ Hard 約15%・約50% ／
Extreme 約10%・約35%。線より少し早く離しただけ（0.1秒早い＝約170km/h）でほぼ返されます。

**離すと跳び上がって振り、離したタイミングで打点が変わります。** 離してから当たるまでは
約0.2秒（跳び上がってラケットを振り上げる時間）で、そのときトスがある高さで打ちます。
トスは 3.3m まで上がりますが、ラケットが届くのは跳び上がって腕を伸ばしきった 2.8m までなので、
線ちょうどで離すとちょうどその最高点で打てます（早く離しても打点はそれ以上高くならず、
威力が弱くなるだけ）。**遅れるほど落ちてきた球を低い打点で打つ**ことになり（線から
0.05秒遅れで約2.65m、0.1秒遅れで約2.4m）、跳ぶ高さも低くなります。打点が低いほど
速い球を入れにくいので、遅れた1本は球速も落ちやすくなります。ポイント後に残る黄色い
軌跡の始点は、この打点（ラケットの位置）です。CPU は常に 2.6m で打ちます。

**サーブの球速はゲージの威力どおりに出ます。** 飛翔時間は狙う距離で正規化してあるので、
コースや深さがランダムに散っても同じ溜めなら同じ速さになります（以前は時間が距離に関係なく
固定だったため、浅い狙いを引くと線ぴったりで打っても 82km/h の緩い球になることがありました）。
ただし打点（2.8m）がネットよりずっと高い関係で、**ネット際へ速い球を通す軌道は物理的に
存在しません** — そのため無入力のときは「その威力で実際に速く打てる深さ」（フル溜めなら
サービスラインから1m以内）だけを狙います。↓ を押して浅く落とすコースは、意図して遅い
山なりの球（前へ引き出す球）になります。

**球種によって球速が変わります。** 真後ろから押すフラット（B）がいちばん速く、擦って回転を
与えるスライス（C）は約1割、トップスピン（V）は約2割遅くなります（フル溜めでおよそ 200 /
185 / 170km/h）。回転の効果（スライスは低く滑る、トップスピンは高く弾む）と球速のトレードオフです。

**強く打つほど、ときどきネットに掛かります**（威力に比例した確率。溜めていないセカンド
サーブならほぼ掛かりません）。ネットに掛かったサーブは救われず、常にフォールトです。

## 練習モード（チュートリアル）

スタート画面で **P**（または「練習モード」ボタン）を押すと、レッスンの一覧が出ます。得点はつかず、
レッスンごとに決まった球を CPU が出し続けるので、操作を1つずつ覚えられます。

- **基本（10）**：移動／サーブ／レシーブ／フラット／トップスピン／スライス／ドロップショット／
  ロブ／ボレー／スマッシュ
- **必殺技（10）**：全10種。その技が出る場面（立ち位置と球）を作ってあり、レッスン中はその技だけを
  装備して、何本打っても回数が尽きません

左上の札に「やること」と成功した本数が出ます。自分の球が相手コートに入り、しかもそのレッスンの
打ち方だったら成功（違う打ち方で入ったときは「何を変えればよいか」が出る）。目標の本数に届くと
「レッスンクリア」で、そのまま続けてもよく、**N** で次のレッスンへ、**Esc** で一覧へ戻ります
（クリアしたレッスンには一覧で ✓ が付く。ページを開き直すと消えます）。

- 球出し役の CPU はその場から動かず、打ち返しもしません。リプレイ・風・スタミナの消耗もなし
  （1本ごとに満タンに戻る）。
- サーブの練習はデュース／アドを交互に打ち、フォールトしてもダブルフォルトにはなりません。
- レシーブの練習の CPU は、遅く確実なセカンドサーブで打ってきます。
- CPU の強さ（レシーブの練習のサーブ）とサーフェス（球の弾み方）はスタート画面の選択どおりです。
- どのレッスンも、人間ができる操作だけのボットで目標の本数に届くことを `tests/smoke.mjs` で
  確かめてあります（立ち位置や出す球は `config.js` の `PRACTICE`）。

## 必殺技

**スタート画面の「必殺技」で、使う技を好きなだけ選べます**（既定は なし＝これまでどおりの
テニス）。**試合中の操作は何もありません** — いつも通り溜めて離すだけで、選んである技のうち
**その場面の条件を満たしたものが1つだけ自動で**発動します。**キックサーブだけは例外**で、
専用のキー **K** でトスを上げたサーブにしか出ません（自分のサーブが全部キックサーブに
なってしまわないように。B/V/C で上げれば普通のサーブ）。トスを上げる前は溜めバーの上に
「K を押してトス → キックサーブ」と出ます。

**それぞれの技が1ゲームにつき1回ずつ**使えます（技どうしで融通はしません）。ゲームが
替わると全部回復します（タイブレーク中はサーブ権が移るたび＝1本目の後、以降2ポイントごと）。残りはスコアボードの下に
`⚡ 必殺技 ● キック ／ ○ ダンク …` と技ごとに出ます（●＝使える／○＝このゲームは使用済み）。
使い切った技は候補から外れるので、**同じ場面でも次の優先度の技が代わりに出ます**
（例：ダンクスマッシュを使った後の高い球は、鷹の目を選んでいればそちらが出る）。

溜めている間は、画面下に「この1打で何が出るか」の予告が出て、溜めバーも金色になります
（回数を使い切っている技が場面に合ったときは、その技名で「使用済み」と出ます）。
**空振りしたときは回数を使いません** — 実際にボールを捉えた（サーブは打った／縮地は跳んだ）
瞬間に初めて1回ぶん減ります。

| 技 | 出る場面 | 何が起きるか |
| --- | --- | --- |
| キックサーブ | 自分のサーブで、B/V/C の代わりに **K** でトスを上げたとき | ネットの上を大きく越して深く入り、**肩の高さまで跳ね上がる**（実測：跳ね1.50m／普通のフラットは0.93m）。溜めすぎてもフォールトせず（満タンの後に押し続けて溜めが抜けると弱くなるのは同じ）、強打のネット掛かりも起きない代わりに、球速は普通のサーブに劣る（134km/h 前後） |
| ダンクスマッシュ | **前に詰めながら**打つ、**頭上の高い（2.2m以上）ノーバウンド**の球 | ネット方向へ2.2m/s以上で走り込みながら、頭より高い打点で叩いたときだけ出る（止まって待って打つのは普通のスマッシュ、**ワンバウンドして跳ね上がった球や、普通のスマッシュの高さ（1.8m）程度の球では出ない**）。打点の上限が0.45m上がって2.95mまで届くので、**通常なら手が届かない高さの球**も打てる。**溜めは要らない**（通常のスマッシュと違って溜め5割の条件が掛からない＝走りながらでも打てる）。**最速およそ270km/h**——通常のスマッシュより4〜5割速く、ベースライン際へ真下に叩き落とす。跳躍も大きくなる |
| ツイーナー | **バウンドした**球に、**真後ろ（左右45°以内）を0.6m以上**抜かれたとき | **抜かれた球を背走で追っている間、足が1.5倍速くなり**（7.2→10.8m/s）、背中側のリーチも1.8倍（2.79m）に伸びる——ロブで抜かれた球はバウンド後12m/sで後ろへ抜けていくので、この2つが無いと打てる一瞬に間に合わない。打球は**相手の位置で2択**：詰めてきていれば頭上を越す深いロブ（75〜85km/h）、下がっていれば低く速い抜き球（110〜130km/h。深い位置から打つほど速い）。背を向けたまま打つのでコースが読まれず、**相手の反応が0.18秒遅れます**。**ノーバウンドの球や、真横を通り過ぎていく球では出ません**——前者はボレーの場面（飛びつきボレー／ドライブボレーの担当）、後者は走って追いつく普通のストロークなので、「自分の真後ろを抜かれた」ときだけに絞ってあります |
| 縮地 | **3m以上離れた**、届かない球 | ボールの前へ**瞬間移動**する（跳ぶ前の位置に金色の残像が残る）。打点に届くまでスイングの有効時間も伸びるので、取れない球が取れる。打球そのものは普通のショット。出せるのは「ボールが3m以上離れていて（ラケットの届く1.55mの倍以上）、かつ全力で走っても次の着地までに追いつけない」球だけ——**ギリギリ届かないだけの球や、走れば届く球では出ません** |
| 飛びつきボレー | ネット前のノーバウンド | **リーチが約2倍**に伸びて飛びつき、サイドライン際へ短く角度をつけて決める。球が届くところまで来る少し前（約0.12秒）に**球のほうへ体ごと飛び込み**（足元も最大1.6m球のほうへ動く）、伸ばしたラケットが球に届いたところで当たる。飛び込んでいる間は動けず、代償として打った後もしばらく動けない（通常0.32秒 → 0.95秒） |
| ドライブボレー | **腰から頭の高さ**に浮いたノーバウンド（0.95m以上、**1.8m未満**） | バウンドを待たずに強打で深く突き刺す。**スマッシュできるくらい高い球（1.8m以上）では出ない**——そこから上はスマッシュ／ダンクスマッシュの領分で、横振りのドライブボレーが拾ってしまわないように上限を切ってある |
| ジャックナイフ | **胸より高く弾んだ球（1.2m以上）**を、**足を止めて**打つ**フラット（B）のバックハンド** | 跳び上がって、高い打点から下向きに叩き込む。**打点が高いほど速く・深くなる**のがこの技の肝で、1.2mでは123km/h・9.3m付近にしかならず、1.8mまで上がったところを叩ければ**249km/h・ベースライン際**まで伸びます（同じ球を通常のフル溜めで返すと206km/h なので、**低く捉えると損・高く捉えると大得**）。**着地点に突っ立ったままではまず出ません**——弾んだ球の頂点は着地点の5mほど後ろに来るので、「高い球だ」と見たら**1.5〜2m 下がって待つ**のが正解（実測：その場だと0%、2m下がると42%の球が条件を満たす）。予告は「その1振りでいちばん高く捉えられる点」で出るので早めに点きますが、実際に低い打点で当ててしまうと普通のバックハンドに戻ります（回数も減りません）。コースは**既定がダウン・ザ・ライン**（自分が立っている側のサイドライン際）で、←→ でクロスにも振れる。バギーホイップとちょうど背中合わせの条件なので、同じ1打で両方が出ることはない |
| バギーホイップ | **フォア側（画面の右）へ大きく振り回された**ときの**トップスピン（V）** | 相手が打ってから右へ2.5m以上走り、センターから2.6m以上右に寄った位置で、**走ってきた勢いのまま（止まってから0.35秒以内に）** **V（トップスピン）** のフォアハンドを振る——この4つがそろった**グラウンドストローク**のときだけ出る（ちょっと横に動いただけの普通のフォアや、フラット・スライス、**ネット前でノーバウンドを触るボレー**、追いついてからじっくり構えて待った1打では出ない）。**追いついて止まってから振っても出ます**（→を押したまま振る必要はない）。最初から右に寄って待っていると「2.5m走った」が満たせないので、**センター付近から追いかける**のがコツ。**打球が空中で横に曲がる**（曲がる向きは打ち方で決まっているので常に同じ＝画面の右から左）。曲がりはバウンドで消える。曲がる球なので**相手の出足が0.25秒遅れます**（ツイーナーと同じ）。**コースは ←→ で2択**（下記） |
| ライジング | **ベースライン付近**（内側1.5m〜後ろ1m）で、**弾んでから0.15秒以内の上がりばな**を捉えたグラウンドストローク | 深い球に下がらず、前で早いタイミングで叩く（ジャックナイフの「下がって高い打点で」とは逆の考え方）。**溜めは要らない**——溜めなしでもフル溜めの通常打と同じくらいの速さで、**深く・相手のいない側へ**返る（←→ を入れればそちらが優先）。打点が低くてもネットに掛からない（通常の強打は、地面すれすれで捉えるとネットしやすい）。**時間を奪うので相手の出足が0.10秒遅れます**。実測では、同じ場面でフル溜めの通常打が決まるのはNormal 34%／Hard 23% のところ、ライジングは 60%／42%。**弾んだ頂点まで下がって待つとまず出ません**（実測：ベースライン上で待てば4〜5割、1m 内側なら7割の1打で条件がそろい、頂点まで下がると3%）。同じ位置に立っていても、振り出しが遅れて引きつけすぎると普通の1打に戻ります（回数も減らない）。ロブ（Shift）とドロップショットでは出ません |
| 鷹の目 | 足を止めて**しっかり溜めた**グラウンドストローク | 狙いのブレが完全に消え、**サイドラインの12cm内側**に落ちる。深さは溜めで選ぶ（つなぎのブロック返球で暴発しないよう、溜め5割以上の1打にだけ乗る）。**ボレーやスマッシュでは出ません**——ネット前は飛びつきボレー／ドライブボレー、頭上はダンクスマッシュの領分 |

**バギーホイップのコースは ←→ で選べます。** 他のショットと同じく**球が当たった瞬間の
入力**で決まり、←→ は移動のキーでもあるので、**追いかけてきた → を押したまま当てると
ストレート**になります。クロスを打ちたいときは、追いついたら → を離して止まってから振って
ください（止まってから0.35秒以内なら技は出ます）。ガイドを出していれば、落下点の目印で
どちらになるか確かめられます。

- **無入力／左（→の逆）＝ クロス**：クロスへ向かって飛び出してから、直線より1mほど
  膨らんで反対側のサイドライン際（ラインの40cmほど内側）へ切れ込むショートクロス。
  Hard の CPU が打ってくるのもこちらで、**相手がフォア側へ振り回されたのを見たら、
  センターへ戻って逆サイドのショートクロスに備えれば届きます**（逆側へ寄っていると決まる）。
- **右（自分のいる側）＝ ストレート**：同じ曲がりが「外へ膨らんでから戻る」向きに働くので、
  **ネットポストの外側を回って**サイドライン際へ戻ってきます（実際のテニスの「ポールを回す
  ショット」。ネットはポストの間にしか無いので、そこを通れば高さは関係ありません）。
  ただしポールを回れるのは**サイドラインの外まで追い出されているとき**だけで、コートの内側
  から打つと物理的に回りきれないため、ふつうの曲がるストレートになります。回れたときは
  コールも「バギーホイップ（ポール回し）」に変わります。

**Hard では CPU/AI も必殺技を使ってきます。** 使うのは **キックサーブ・ダンクスマッシュ・
ツイーナー・ドライブボレー・ジャックナイフ・バギーホイップ・ライジング・鷹の目**の8種で、効果も回数（1ゲームに1回ずつ）も
人間とまったく同じ。よく出るのは鷹の目・キックサーブ・ドライブボレー・ダンクスマッシュで、
ツイーナーだけは AI の動きの都合でめったに出ません（背走ダッシュは人間の入力にだけ
掛かります）。AI は弾んだ頂点へ回り込んで待つので、ライジングは深い球に下がりきれなかった
ときに出ます（それでも鷹の目・バギーホイップと同じくらいの頻度）。**飛びつきボレーと縮地だけは AI に持たせていません**——どちらも「本来なら
届かない球に届く」技なので、AI に渡すと守備範囲を広げることになり、こちらの決め球が
決まらなくなるためです。ダブルスの味方AIも同じように使います。なお**スタート画面で技を
1つも選んでいなければ AI も使いません**（何も選ばなければ従来とまったく同じゲーム、の
ままです）。

**Extreme では、その「渡していない2種」まで解禁されて、全10種を1ゲームに3回ずつ使ってきます。**
条件がそろえばほぼ必ず出す（Hard は7割）ので、Hard で決まっていた球が返ってきます。
- **飛びつきボレー**：ネット際で、普通のリーチでは届かないノーバウンドの球に飛びつく。
  代償も人間と同じで、打った後しばらく動けません（＝2本続けて抜けば決まります）。
- **縮地**：走っても間に合わない球で、打点へ瞬間移動する。判断は**その球について1回だけ**
  ——ネットを越えてきた瞬間に「この足では間に合わない」と見たときだけで、跳んだ後は
  普通の1打を打ってきます（跳び先は「本来そこへ走りたかった場所」なので、返球も弱くなりません）。
  跳ぶ前に立っていた位置には、人間の縮地と同じ金色の残像が一瞬だけ残ります。

どれも**狙いが荒れません**（通常のライン際狙いにある「やりすぎると15%ほどサイドアウト」が
ない）。複数の技が同時に条件を満たす場面では、上の表の**上にある技が優先**されます
（＝「高い球ならダンクスマッシュ、届かないなら縮地」のように場面で棲み分かる）。技を1つしか
選ばなければ、その技が出る場面だけで使えます。

必殺技で取ったポイントは、球種の代わりに技名がコールされます。使った回数は試合後の
スタッツ画面にも並びます（1回も使わなかった試合では行ごと出ません）。

## テニスのルール

- 試合開始時は実際の試合と同じくトス（コイントス）から始まり、勝った側がサーブ／レシーブを
  選ぶ。人間が勝てばスタート画面で選ばせ、CPUが勝てば自動で選ぶ（サーブを選ぶ確率が高め）。
  選んだ結果に応じて第1ゲームのサーバーが決まり、以降のゲームごとの交代（ダブルスの
  パートナーの巡りも含む）はいつもどおり続く。
- サービスサイドはクロス（-1）から始まり、ポイントごとに逆クロス（+1）と交互になる。
- サーブはノーバウンドで打ち返せない（1バウンドしてから返球する）。
- ラリー中にネットへ掛かった球は、ごく低い確率でそのままネットコードに救われて相手コートへ
  入り続ける（**ネットイン**。「ネットイン！」のコールと専用の音で知らせる）。それ以外は
  従来どおりその場で失点。サーブがネットに触れた場合は対象外で、常にフォールトのまま。
- レシーバーはポイント開始時、狙われる対角のボックス付近（レシーブポジション）へ自動で移動する。
- ダブルスでは、サーバーはゲームごとにチームが交代し、各チーム内でも次に自分たちの番が
  来るたびにパートナーと交互になる（実際のルールと同じ）。レシーブするコート（デュース/アド
  相当）は各選手で固定：主力(you/cpu)は+1側、パートナーは-1側を必ず受ける。
- 6ゲーム-6ゲームになったら、通常のゲームの代わりに7ポイント先取・2点差のタイブレークを行い、
  取った方がそのままセット（7-6）を取る。タイブレーク中はスコア表示が0/15/30/40ではなく素点になり、
  サーバーは1本目だけ現在の担当のまま、以降は2ポイントごとに交代する。ダブルスはタイブレーク中も
  セットと同じ順番で4人が回り（例：あなた→CPU→パートナー→CPU2→あなた…、1本目以外は2本ずつ）、
  レシーブするコートもセットと同じまま。タイブレークで決まったセットの次のセットは、タイブレークの
  1本目をレシーブした側のサーブから始まる。
- **チェンジエンズ（コートの入れ替わり）は実際のルール（ITF ルール10・29）どおり。**
  各セットの第1・3・5…ゲーム（奇数ゲーム）の後に入れ替わる。セットの終わりは、そのセットの
  ゲーム数が奇数（6-3・7-5・タイブレークで決まった7-6 など）なら入れ替わり、偶数（6-4 など）なら
  入れ替わらずに次のセットの第1ゲームの後で入れ替わる。タイブレーク中は6ポイントごと。
  - 入れ替わるときは画面が暗転し、「チェンジエンズ」のコールの間にコートを入れ替える。
    自分はいつも手前から打つので、入れ替わったことは**会場の向き**で分かる：審判台・線審・
    ボールボーイ・観客・日の当たる向きが反対側になり、リプレイのカメラも会場の反対の脇から映す。
    会場に吹いている**風も、選手から見た向きが逆になる**（スコアボード下の矢印が反転し、追い風だった
    エンドから向かい風のエンドへ移る）。
  - 休憩も実際のルールに合わせてある。ふつうの入れ替わりは90秒の休憩、セット間は120秒の休憩が
    あり、その間に**スタミナが多めに戻る**（ポイント間の回復の 3.5 倍／セット間は 4.5 倍。終盤ほど
    目減りするのはポイント間と同じ）。各セットの第1ゲームの後とタイブレーク中は休憩なしで
    すぐ入れ替わる。実際の90秒は待たせず、暗転を少し長く置くだけで表す（Space で切り上げられる）。
- **次の1点に何がかかっているかが、スコアボードの下に出る。** あと1点でそのゲームが決まる
  場面で、サーブ側なら「ゲームポイント」、レシーブ側なら「ブレークポイント」、そのゲームで
  セットまで決まるなら「セットポイント」。色でも分かれる（ブレーク＝赤／セット＝金／
  ゲーム＝黄緑）。デュースのように何も決まらない1点では出ない。**タイブレーク中は
  取ればセットなので、あと1点の側に常に「セットポイント」が出る。**
  かかっていた1点は観客の沸き方も変わり、決めたときはもちろん、**ブレークポイントを
  凌いだときにも拍手が起きる**。ブレークで取ったゲームはコールが「ゲーム — YOU（ブレーク！）」になる。
- ポイントが決まると、取った側がそのポイントで最後に放ったショットの球種（スマッシュ／ボレー／
  ロブ／ドロップショット／スピンショット／スライスショット／フラットショット）がコールと一緒に
  出る。サーブで決まったときは球種とコースまで出す（例：「スライスサービス（ワイド）」
  「フラットサービス（センター）」）。相手のネット・アウトで決まった場合は「そのミスを誘った
  自分の1本」になる。
- **CPU/AI の走る速さは実際のテニス選手のコート上の最高速（5〜6m/s）に合わせてある**
  （Easy 4.8／Normal 5.8／Hard 6.4／Extreme 7.0 m/s。人間は 7.2m/s だが、加速があるので1秒では実質
  6.2m 相当＝Extreme はほぼ互角の足になる）。以前は Hard が 10.2m/s ＝ 36.7km/h とボルトの100m平均並みで、**どんなに
  良いコースへ打っても足の速さが上限まで使われず、左右に振ってもまず抜けなかった**。
  いまはサイドライン際へ振り切れば抜ける（実測：Hard で拾われる割合 97%→90%、人間の
  ウィナーが約2倍）。難易度の差は主にリーチ・反応の速さ・ミス率が受け持つ。
- CPU/AI の守備範囲は「反応に使える時間」で決まる。打たれてからボールが自分に届くまでが
  短いほど狭くなり、スマッシュや至近距離のボレーは体のすぐ近くしか触れない（ダブルスの前衛が
  スマッシュを高確率で拾ってしまう問題への対策。1バウンドを挟む普通のラリー球は従来どおり）。
  さらに**0.2秒ほどで届いてしまう球には反応そのものが間に合わない**（見てから体を動かす
  時間がないので、体の正面へ来た球にラケットが当たるだけ）。ネット際の前衛同士が3mほどの
  至近距離でボレーを打ち合い続ける、という現実には起きない形を防ぐため。
- 会場には試合ごとに決まった向きの風（卓越風）が吹き、ポイントごとに強さと向きが少しずつ揺れる
  （スコアボード下に「風 ↗ 0.3 追い風」のように、画面上の向きと自分から見た追い風／向かい風／横風を
  表示）。向きは試合を通して最大30°ほどしか振れないので、**風上と風下のエンドがある**。横風は球を
  横へ流し、追い風は打球を伸ばして（ロブや深い球はアウトしやすい）、向かい風は押し戻して浅くする。
  同じ風は相手には逆に効く。サーブの飛翔（トス〜1本目の着地）は無風のまま行われ、返球された瞬間から
  ラリー中の球だけが風に流される。
- サーブを打った瞬間の初速がスコアボード脇に「サーブ 172km/h」のように出る（人間・CPU/AI
  どちらも）。次のポイントが始まるまで表示が残る。
- CPU/AI は、人間がネットに詰めているときにロブ一辺倒にはならず、足元へ沈める短い球・
  サイドライン際へのパッシング・ロブを状況で撃ち分ける。ロブを多めに選ぶのは人間が
  ネットのすぐ近くまで詰め切っているときだけ。
- CPU/AI（相手・パートナーとも）はボレーとスマッシュを打ち分ける。ネット際でノーバウンドに
  捕まえた球はボレーになり、**高い打点を余裕をもって捕まえたときだけ**サイドライン際へ短く
  角度をつけた鋭い決め球になる（足元へ沈められた球や大きく振られた球は中央寄りのブロック返球）。
  頭上に上がってきたロブはバウンドを待たずに空中で叩きにいき、深く速いスマッシュで決めにくる。
  ただし**ダブルスで「下がれ」（E）を指示してあるパートナーだけは前へ出て叩きにいかない**：
  自陣の後ろ半分（サービスラインより奥）に落ちてくるロブなら下がったまま叩きますが、それより
  手前に落ちるロブは1バウンドさせてから返します（指示どおり下がったままでいるため）。
- **ダブルスは、ソフトテニスのような雁行陣（後衛＋前衛）で戦う。** 各ペアは役割が決まって
  いて（後衛＝ベースラインでラリーを作る CPU／YOU、前衛＝ネット際で決めにいくパートナー・
  CPU2）、球の深さで担当が分かれます。深い展開球は後衛、ネット際に落ちる短い球は前衛。
  「落下点に近い方が取る」ではないので、中途半端な深さの球のたびに前衛が下がって陣形が
  崩れる、ということが起きません。前衛がポーチに出ている間、後衛はベースライン付近で
  逆サイドを開けて守ります。
  - **前衛の立ち位置は展開で変わります。** 相手後衛と味方後衛が**対角（クロス展開）**なら、
    相手のストレートは味方後衛のいない側へ来るので、前衛がその線を塞ぎに寄って守る。
    **同じ側（ストレート展開）**なら、ストレートは味方後衛が見られるので、前衛は真ん中を
    越えてラリー側へ踏み込み、ネットにも半歩詰めた**攻めの姿勢**で構えます。
  - **前衛はタイミングを見計らってポーチ（横取り）に出ます。** 相手が打った瞬間に「出る」と
    決め、走って間に合う迎撃点があればストレートを捨てて中央へ飛び出します（間に合わないと
    判断した球には仕掛けません）。出ていく頻度は能力値「ネット志向」で変わります。
    仕掛けなくても、自分の半歩ぶん前後を通る球には手が届くので、目の前を素通りさせません。
  - **後衛の配球は「相手前衛を避けてクロス、隙があればストレートを抜く」。** 基本は相手前衛の
    逆サイドへ深く運び、前衛が中央へ寄ってポーチを狙っている（＝ストレートが空いている）
    ときに、自分に余裕があればサイドライン際へパッシングを通します。走らされているときは
    無理をしません。
  - **ネット際で打つボレー・スマッシュは、目の前の相手を「横切らない」。** 相手の逆サイドへ
    打つと、2人ともネット際にいるぶんその球は相手の真ん前を至近距離で通ることになります。
    代わりに相手の**外側**（自分がいる側）へ抜き、サイドを締められていて抜く隙間が無ければ
    ボレーは**頭を越します**（ロブボレー）。大きく外へ切れるのは高い打点を余裕をもって
    捕まえた決め球のときだけで、足元へ沈められた苦しいブロックは相手のすぐ外を通すのが
    精一杯です。
- シングルスの CPU/AI も、余裕をもって深く狙えた1本（アプローチショット）の後は一定確率で
  ネットへ詰め、そのまま前でボレーしてくる（詰めている間は下がらず、届く範囲でいちばん前の
  位置で迎え撃つ）。ロブなどで深く押し戻されたらネットは諦めてベースラインに戻る。
  詰めてくる頻度・ボレーの鋭さ・スマッシュの速さは強さ（Easy/Normal/Hard/Extreme）で変わる。
- コートサーフェスを ハード／クレー／芝 から選べる。クレーは高く弾んで減速し（ラリーが
  長引きドロップが効く）、芝は低く滑って伸びる（ネットプレー有利）。ハードは既定の物理と
  完全に一致する。
- **クレーでは球の跡（ボールマーク）がコートに残る。** 跡は打球の進む向きに伸びた楕円で、速い球ほど
  長く滑る。チェンジエンズでは会場ごと回るので跡もコートに付いたまま入れ替わり、セットが終わると
  ブラシがかかって消える。クレーの試合にはホークアイがなく、際どい判定は主審が跡を見て確かめる。
  その代わりに、線から10cm以内のアウト（ダブルフォルトを含む）で決まったポイントは、リプレイの
  最後に跡を真上から映す（「ボールマーク確認」）。跡は「線に掛かっていればイン」と必ず一致する
  位置に描く。
- CPU/AI にプレースタイルを持たせられる（強さとは別軸）。サーブ&ボレーヤーはサーブ後に
  ネットへ詰め、リトリーバーはミスしにくくよく走りロブを多用し、ベースライナーは
  コースを広く速く突く代わりミスも増える。
- ポイントが決まると、直近の攻防をコート脇の低いアングルからスロー再生する。再生中は
  画面上部に「リプレイ ／ SPACE でスキップ」と出て、次のポイントの開始を待つ。
  スキップできるのは Space だけ（次の構えでラリー用のキーに触れても飛ばない）。
- **線審がコールする。** 球が線を割ると、その線の担当の線審が「アウト！」（サーブなら
  「フォルト！」）と叫び、出た方向へ片腕を水平に伸ばす。ベースラインはその側の線審、
  サイドラインはその側の線審、サービスライン・センターサービスラインはその半面の線審が受け持つ。
  ライン際（線から15cm以内）に入った球には、無言で両手を体の前にそろえる「セーフ」の合図を出す
  （余裕をもって入った球には何もしない）。コールで決まったポイントは、実際の中継と同じく
  コールを一拍見せてからリプレイに移り、リプレイも着地の瞬間のコールまで映して少し長めに止まる
  （手前のベースラインの線審は通常のカメラの外にいるので、リプレイで見える）。
- 長いラリーで走るとスタミナが減り、移動速度と（人間の）溜め速度が少し落ちる。人間・CPU/AI
  とも同じルールで効き、ポイント間で少し回復する。スコアボード脇に自分だけでなく相手・
  パートナーも含めた全員（シングルスはYOU/CPU、ダブルスはさらにパートナー/CPU2も）の
  残量バーを常時表示し、相手やパートナーの消耗具合も駆け引きの材料にできる
  （閾値を下回ると赤くなる）。
- 1セットが終わると、その試合の振り返り（スタッツ画面）が出る。最終スコアと、両チームの
  獲得ポイント・1stサーブが入った割合・エース・ダブルフォルト・ウィナー・ミス・
  ブレークポイント・最速サーブを左右に並べ（上回っている側の数字が色付き）、下に総ポイント数・
  最長ラリー・平均ラリーを出す。ブレークポイントは「決めた本数／チャンスの本数」（例 3/5）で、
  勝っている側の目印は割合ではなく**決めた本数**で付ける（1/1 が 4/8 を上回って見えるのは
  おかしいため）。どちらにもチャンスが無かった試合では行ごと出ない。
  出ている間は試合の進行が止まり、「次の試合へ」（Space／Enter／ボタン）で閉じると次の試合が
  始まる。最後のポイントのリプレイを見終わってから出る。
- ポイントが決まると観客のざわめき／歓声が鳴る。ラリーが長引くほど、そしてエースより
  ウィナーのほうが盛り上がる（長いラリーの末のウィナーが一番大きく長く鳴る）。
  さらに**ブレークポイント／セットポイントがかかっていた1点は、決めても凌いでも大きく長く沸く**
  （いちばん大きいのは「長いラリーの末に決まったセットポイント」）。
- **観客は実際の会場のように静まる。** ポイントの合間（決着の後・リプレイ・チェンジエンズの休憩・
  スタッツ画面）は話し声のざわめきが流れ、サーブの構えに入ると静まって、ラリー中は無音になる
  （1本目のフォールトからセカンドサーブまでも静かなまま）。ライン際（線から8cm以内。イン・アウトとも）に
  落ちた球には「おぉ…」と声が漏れ、ダブルフォルトにはため息が出る。声はどれも音源ファイルを使わず、
  十数人ぶんの声を母音のフォルマントに通して合成している（ざわめきは12人の話し手が音節ごとに母音・
  声の高さ・強さを変えながら話し、ときどき息継ぎで途切れる）。

## 構成

```
index.html          DOM（HUD とスタート画面）と script の読み込み順
styles/main.css     HUD のスタイル
vendor/three.min.js three.js r128（同梱）
assets/ogp.png       SNSカード用の画像（1200x630）。元データと焼き直し手順は assets/ogp.html
src/
  config.js         寸法・物理・難易度・選手の能力値・必殺技などのチューニング値
  math.js           clamp / rand / approach など
  physics.js        弾道の積分、落下点の予測、初速の逆算（純粋関数）
  scoring.js        ポイント表記とゲーム／セットの成立判定（純粋）
  ai.js             CPU の位置取りと狙い先（ダブルスの雁行陣もここ）
  game.js           ルールと状態遷移（three.js にも DOM にも触らない）
  input.js          キーボード／ポインタ入力
  hud.js            スコアボード・コール表示・スタート画面のGUI（DOM に触る唯一の場所）
  audio.js          Web Audio による効果音（打ち方・スピン・サーフェスで音色を変える3層合成）
  scene/
    renderer.js     レンダラー・カメラ・ライト
    court.js        コート面（ラインは CanvasTexture）とスタンド
    marks.js        クレーのボールマーク（球の跡）
    crowd.js        観客（スタンド上に InstancedMesh でひな壇状に並べる）
    net.js          ネットとポスト
    officials.js    審判台・主審・線審・ボールボーイ（装飾。線審だけコールの合図で腕を動かす）
    player.js       選手のメッシュ（両腕・ラケット）と振り付け（キーポーズの補間＋腕のIK）
    ball.js         ボール・擬似影・着弾フラッシュ・直近1打の軌跡
    hint.js         スマッシュの先回り地点マーカー
    world.js        シーンの組み立てと「状態 → メッシュ」の反映
  main.js           起動点。配線とフレームループだけ
```

各ファイルは即時関数で包まれていて、`window.RallyOne` に自分の分だけを足していきます。
先頭で使うものを分割代入しているので、そこがそのファイルの依存一覧です。

```js
(function (RallyOne) {
  'use strict';
  const { COURT, PHYSICS } = RallyOne.config;  // ← これが import 相当
  ...
  RallyOne.physics = { netHeightAt, ... };     // ← これが export 相当
})(window.RallyOne = window.RallyOne || {});
```

`index.html` の `<script>` は依存順に並んでいるので、**ファイルを追加したらここにも1行足す**こと。

依存の向きは `main → game → (physics / scoring / ai / config)` と `main → scene/*` の二方向で、
ゲームロジック側は three.js も DOM も参照しません（= Node でそのままテストできる）。

## 開発メモ

- コンソールから `RallyOne.game` で現在の状態（ボール、選手、スコア）を覗ける。
- `game.js` は `hooks`（音・コール・スコア更新）を注入される。表示を変えたいときはここを差し替える。
- 難易度は `config.js` の `CPU` と `PLAYER` を触る。Normal は「素の値」そのもので、
  easy/hard/extreme は `CPU_LEVELS` がその上から必要なキーだけを上書きする（＝素の値を動かすと
  変わるのは Normal だけ）。AI が必殺技をどう使うか（一覧・回数・出す確率）も
  `CPU.SPECIAL_ALL_MOVES` / `SPECIAL_USES` / `SPECIAL_CHANCE` として同じ仕組みに乗っている。
- 選手の動き（全員右利き）は `config.js` の `MOTION` に、打ち方ごとの「手の位置・ラケットの向き・
  逆手・体のひねり」をキーポーズとして並べてある。肘の角度は `scene/player.js` の2関節IKが逆算するので、
  振り付けを直すときは手とラケットの位置だけ考えればよい。左手はサーブのトス、構えでスロートに添える、
  両手バックハンドでグリップを握る、を受け持つ（片手／両手は `MOTION.BACKHAND` で選手ごとに選べ、
  両手打ちでもスライス・ドロップ・ボレーは片手）。跳躍・脚の形は `SWING`、歩行は `GAIT`。
- ポイント間の待ち時間は `setTimeout` ではなくゲームループ内のタイマー（`Game#after`）で数えているので、
  ポイントがリセットされると必ず破棄される。
- ES モジュール（`import`/`export`）は使っていない。`file://` で開けなくなるため。
- ロジック層の回帰テストは `node tests/smoke.mjs`。three.js も DOM も使わず、Node だけで検証する。
- タスクのバックログは [docs/ROADMAP.md](./docs/ROADMAP.md)。`/loop 2h /evolve` のように定期実行すると、
  そこから1件ずつ拾って実装・テスト・コミットする（詳細は [.claude/skills/evolve/SKILL.md](./.claude/skills/evolve/SKILL.md)）。
