## 2026-08-23 CPUのレシーブ位置がミドルに寄ってしまう問題を修正（ユーザーフィードバック対応）
- ブランチ: なし（ユーザーからの直接指示で本会話中に実装）
- 実施内容: ユーザー報告「敵のレシーブ位置がおかしい。ミドルに立つのではなく、サイドライン付近が適正」を調査。2つの原因を発見して両方直した。

- テスト: `node tests/smoke.mjs` — ALL PASS。新規回帰テスト追加：レシーブの構えがボックス中央ではなくサイドライン寄りであること、人間がトス/溜めをしている複数フレームの間、CPUの位置が1mmも動かないこと。ブラウザ実機（`claude-in-chrome`、ローカル`http.server`経由、ハードリロードで確認）でも、修正前は`newPoint()`直後の1.5秒でx=3.615→0（センター）まで歩いてしまうこと、修正後はサーブが打たれるまでx=3.615のまま動かないことを確認。コンソールエラーなし。
