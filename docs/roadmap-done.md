## 2026-08-19 打点のタイミングでコースが変わる（早い=引っ張る／遅い=流れる）
- ブランチ: なし（/evolve 経由ではなく、ユーザーからの直接指示で本会話中に実装）
- 実施内容: `config.js` に `TIMING_AIM`（`NEUTRAL_DZ`/`HALF_BAND`/`MAX_SHIFT`/`OUT_MARGIN`）を追加。実プレイでの打点位置（`ball.z - you.z`）をシミュレーションで実測（0.58〜1.50mの範囲）し、その中央 0.95m を「ずれない」基準点にした。`game.js` の `hit()` で `classifyStroke()` を `shot` 計算より前に移動し、`playerShot(stroke, contactDz)` へ打点情報を渡すように変更。フォアハンドとバックハンドは体を横切る向きが逆なので、`pullDir = (stroke==='forehand' ? -1 : 1) * RACKET_SIDE.you` で引っ張る方向を反転させている。ロブは対象外。人間（'you'）のみに適用（AIは届いた瞬間に自動で振るためタイミングの意図がない）。←→ の方向指定とは加算で合成される。
- テスト: `node tests/smoke.mjs` — ALL PASS。フォア早打ちは-MAX_SHIFT、フォア振り遅れは+MAX_SHIFT、バックハンドは同じタイミングで符号が逆になること、ロブが影響を受けないこと、←→ 入力と合成されること、通常タイミングならコート内に収まることを新規テストで検証。ブラウザでも同じ結果を確認（フォア早い=-3.98, フォア遅い=+1.20, バック早い=+1.19, バック遅い=-3.99）。5分間のマッチシミュレーションでもフリーズ・エラーなし。
