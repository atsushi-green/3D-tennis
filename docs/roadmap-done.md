## 2026-08-20 ダブルスのパートナーAI（youMate）を修正：サーブ前のフットフォルト・レシーブできない・挙動不安定
- ブランチ: なし（/evolve 経由ではなく、ユーザーからの直接指示で本会話中に実装）
- 実施内容: ユーザー報告「パートナーのサーブが前にでてフットフォルトしている」「パートナーがほとんどレシーブできない」「すぐネットに出たり挙動が不安定」の3点を調査し、根本原因は2つと判明。
  1. **サーブ前のフットフォルト**: `moveDoublesTeams()` が `phase==='serve'`（サーブ待ち）中も毎フレーム通常のラリー用「追う/構える」ロジックを動かし続けていたため、`newPoint()` が置いたサービス/レシーブのスタンスから、サーバー本人も含めて全員がネット際の構え位置へ寄っていってしまっていた。`moveDoublesTeams()` の先頭で `phase==='serve'` なら4人とも一切動かさず（`speed=0` のみ）即 return するように変更。レシーブ側の2人（サーバーではないチームの2人）もサーブが来る前に構えを崩されなくなった。
  2. **レシーブできない／挙動不安定**: `ai.js` の `chasePosition(ball)` が cpu 陣地（z>0）基準の定数（`CPU.CHASE_Z_MIN/MAX/BEHIND`）だけを使っており、常に z>0 の値を返す実装になっていた。`cpu`/`cpuMate` が使う分には問題ないが、`youMate`（you 陣地・z<0）が同じ関数をそのまま使っていたため、自陣に来た球を追おうとすると常にネットの向こう側（cpu 陣地寄りの z≈1.6〜2.1）へ向かってしまい、実際の落下点を追えていなかった。`chasePosition(ball, side)` に `side` 引数を追加（既定 `1`＝従来通り）し、`side=-1` のときは z 方向を鏡映しにする式に変更。`moveDoublesTeams()` の youMate 側の呼び出しだけ `chasePosition(ball, -1)` を渡すようにした。
- 副次的に見つけた点: 上記2つを直した結果、youMate が cpu チームと同等に強くなり、シミュレーションテストで「両チームとも完璧に拾い続けて点が全く決まらない」退行を誘発した（静止したまま延々と Space を叩くだけの非現実的なテスト入力が原因）。テストの入力を実際のプレイに近い「動き続ける人間」に変更して解消（ゲームロジック自体の変更はなし）。
- テスト: `node tests/smoke.mjs` — ALL PASS。新規テスト: `chasePosition(ball, side)` の鏡映し（side=-1 で自陣側に留まること、浅い着地でもネット向こうへ出ないこと）、サーブ待ち中は4人とも（サーバー本人だけでなくレシーブ側の2人も）`newPoint()` のスタンスから動かないこと（you/cpu 両チームのサーブで確認）。ブラウザで実際に youMate をサーバーにして `g.update()` をコマ送りし、CPU_SERVE_DELAY(0.9s) の間スタンスが1mmも動かないこと、その後正常にサーブが発火することを確認。10分間のダブルスシミュレーション（動く人間入力）で youMate のヒット数が cpu 陣営と同程度（同じ試行で cpu 56 / youMate 64 / cpuMate 23 / you 15）になり、フリーズ・タイマーリーク・コンソールエラーなしを確認。

- 実施内容: ユーザー報告「サーブが逆クロススタートになっている」を調査。カメラはベースライン後方の負のz側から+z方向を見ており、**world +x が画面左に映る**（`INPUT_X_TO_WORLD=-1` の既存コメントの通り）。`scoring.js` の `serveSide` は 0点(偶数)を `+1` としていたため、フレッシュな試合の1本目のサーブでサーバーが world +x＝画面左に立ってしまい、実テニスの放送アングル（1本目はデュース/クロス＝画面右からのはず）と逆に見えていた。`serveSide` の三項演算子の分岐を入れ替え、偶数を `-1`（クロス）、奇数を `+1`（逆クロス）に修正。呼び出し側3箇所（`game.js` の `newPoint()`/`serve()`）は式（`targetSign = team==='you' ? -side : side` 等）を変えず、符号の意味だけが反転する形にして一箇所の修正で済むようにした。
- テスト: `node tests/smoke.mjs` — ALL PASS。符号反転に伴い、フットフォルトの可動域テスト（サイドライン/センターマークの期待値）、クロス/逆クロス交互のテスト、サーブコース（ワイド/T）が ←→ のどちら入力に対応するかのテスト、ダブルスのレシーバー固定テスト（フレッシュな試合では今度は youMate が受ける側になる）を新しい符号に合わせて更新。ブラウザで実際に開始し、1本目のサーブでサーバーが画面右（デュースコート相当）に立つこと、得点後は画面左（アドコート相当）に切り替わることを目視確認。コンソールエラーなし。
