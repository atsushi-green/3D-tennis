# ROADMAP

`/evolve` skill（`.claude/skills/evolve/SKILL.md`）がこのファイルを読んで、1サイクルにつき1項目だけ拾って実装する。
完了した項目は [docs/roadmap-done.md](./roadmap-done.md) に移す。

## 書式

```
- [ ] <サイズ> <タイトル> — <補足・受け入れ条件>
```

- **サイズ**は `S`（1サイクルで確実に終わる小さな修正）／`M`（1サイクルで終わるが設計判断を伴う）／`L`（複数サイクルにまたがる、または着手前に方針を相談すべき大きな機能）。
- `/evolve` は **`S` と `M` だけを自動で拾う**。`L` は拾わない（人間がサイズを分解して `S`/`M` に落とすか、方針を決めてから着手する）。
- 優先度は上から順。追加するときは狙う位置に挿入する（末尾ではなく）。
