# ROADMAP

`/evolve` skill（`.claude/skills/evolve/SKILL.md`）がこのファイルを読んで、1サイクルにつき1項目だけ拾って実装する。
完了した項目は [docs/roadmap-done.md](./roadmap-done.md) に移す。

## 書式

```
- [ ] <サイズ> <タイトル> — <補足・受け入れ条件>
```

- **サイズ**は `S`（1サイクルで確実に終わる小さな修正）／`M`（1サイクルで終わるが設計判断を伴う）／`L`（複数サイクルにまたがる、または着手前に方針を相談すべき大きな機能）。
- `/evolve` は **`S` と `M` だけを自動で拾う**。`L` は拾わない（人間がサイズを分解して `S`/`M` に落とすか、方針を決めてから着手する）。
- 優先度は上から順。追加するときは狙う位置に挿入する（末尾ではなく）。

## 未着手

- [ ] M CPUがロブを打たず、シングルスで人間がスマッシュを打てる機会がほぼ発生しない — スマッシュ本体のモーション・判定は実装済みで動作確認済み（`docs/roadmap-done.md`参照）。だが`ai.js`にCPU用のロブ判定がなく、CPUは常に通常の低い弾道でしか返球しないため、`PLAYER.SMASH_MIN_Y`(1.8m)を満たす高い球が実戦でほぼ来ず、スマッシュの見た目を確認する機会が乏しい。CPUがたまにロブを選ぶようにする／閾値を見直す等、方針を決めてから着手する。
- [ ] CPUのレシーブが弱く感じます。正面に強く打てばサービスエースになりやすいですし、そうでなくても返球が全体的に弱いです。
- [ ] プレイヤーはストロークの時に溜めやすすぎます。移動していると溜められなくなるようにして、溜めやすさを調整してください。
- [ ] サービスのときのトスをもっと高くしてください。
